PROJECT / 01

Active Directory
Home Lab

Built a simulated company domain using Windows Server 2022, AD DS and DNS. Joined three Windows 11 clients, applied Group Policy, configured access permissions and practiced Help Desk scenarios.

OBJECTIVE / Create a realistic Windows domain for three departments and practice everyday IT support tasks.

Implementation & verification
Environment
Windows Server 2022 domain controller in VMware Workstation; three domain-joined Windows 11 clients.
Implementation
Configured AD DS, DNS, organizational units, users and security groups for IT, HR and Finance; applied GPO restrictions and NTFS/SMB access permissions.
Verification
Tested domain sign-in, policy application and department share access; rehearsed password resets, account unlocking and group-membership fixes.
